slate.http.http_task

Background HTTP task execution integrated with Slate UI event loop and tasks.

Discussion

This module bridges slate.http transfers with slate.tasks (spawnCompute and runCompute), forwarding download progress to UI components and marshaling completion callbacks to the Slint UI event loop or caller dispatch thread without blocking UI rendering.

  • runHttpTask

    Declaration

    Nullable!Response runHttpTask(const Request req, ClientConfig config, void delegate(float) onProgress = null, void delegate(Nullable!Response) onComplete = null, TaskCancellation cancellation = null, void delegate(void delegate()) dispatch = null);

    Synchronous core: runs an HTTP request under runCompute!Response on the calling thread.

    Discussion

    Progress updates are coalesced and throttled via slate.tasks.ProgressGate. Final completion callback is guaranteed to run through dispatch (TC-08).

  • spawnHttpTask

    Declaration

    TaskCancellation spawnHttpTask(const Request req, ClientConfig config = ClientConfig.init, void delegate(float) onProgress = null, void delegate(Nullable!Response) onComplete = null);

    Spawns an HTTP request on a dedicated background worker thread.

    Discussion

    Returns a TaskCancellation handle allowing cooperative abortion of the transfer (EV-4, TC-08). On native builds, callbacks are dispatched through the Slint event loop (slint.invokeFromEventLoop).

auto stub = new HttpStubServer("Task Transfer Completed Successfully", false, 0);
scope (exit) stub.close();

import std.format : format;
string url = format("http://127.0.0.1:%d/task_get", stub.port);

float lastProgress = 0.0f;
bool completed = false;
Nullable!Response finalResponse;

void onProgress(float pct)
{
    lastProgress = pct;
}

void onComplete(Nullable!Response res)
{
    completed = true;
    finalResponse = res;
}

bool dispatchCalled = false;
void testDispatch(void delegate() job)
{
    dispatchCalled = true;
    job();
}

auto cancellation = new TaskCancellation();
auto res = runHttpTask(Request.get(url), ClientConfig.init, &onProgress, &onComplete, cancellation, &testDispatch);

assert(!res.isNull, "Expected successful response");
assert(res.get.status == 200);
assert(res.get.bodyAsString() == "Task Transfer Completed Successfully");
assert(completed, "Expected onComplete to be called");
assert(!finalResponse.isNull);
assert(dispatchCalled, "Expected dispatch callback to be invoked");

    Examples

    Example: 

    1. import slate.http.http_task;
import slate.http.request;
auto cancel = spawnHttpGet("http://example.com/slow");
cancel.cancel();

    1. // Best practice: verify in-flight task cancellation aborts transfer cleanly and reports null result
auto stub = new HttpStubServer("Delayed task response", false, 500);
scope (exit) stub.close();

import std.format : format;
string url = format("http://127.0.0.1:%d/slow_task", stub.port);

bool completed = false;
Nullable!Response finalResponse;

auto cancel = spawnHttpGet(url, null, (res) {
    completed = true;
    finalResponse = res;
});

import core.time : dur;
Thread.sleep(dur!"msecs"(50));
cancel.cancel();

int waited = 0;
while (!completed && waited < 20)
{
    Thread.sleep(dur!"msecs"(50));
    waited++;
}

assert(completed, "Cancelled task must complete");
assert(finalResponse.isNull, "Cancelled task result must be null");
