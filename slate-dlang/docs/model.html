slate.agent.model

Data models for UI automation, inspection, snapshotting, and diagnostics.

Discussion

Exact port of slate_agent::model: geometry, selectors, tree nodes, screenshots, state, and action results — including the serde wire shapes (externally-tagged selector enum, skip_serializing_if omissions), re-expressed with std.json. Async-free: pure data, fully unit-tested.
